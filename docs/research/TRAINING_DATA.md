# Training-Data Dossier — Perathos VRL Verifier Modules

**Last researched: 2026-06-16**

This dossier identifies, verifies, and licenses real-world training/evaluation datasets
for two Perathos VRL verifier modules:

- **ClaimEntailmentVerifier (124)** — decomposes an output into atomic claims and labels
  each `supported` / `contradicted` / `unverifiable` against retrieved evidence
  (NLI / fact-verification / retrieval-entailment).
- **CrossExaminer (122)** — self-consistency: compares the primary output against
  resamples; disagreement signals hallucination.

Every dataset below was checked against its official HuggingFace card, GitHub repository,
and/or the arXiv / ACL Anthology paper. License notes are deliberately conservative:
where a dataset is a **meta-benchmark** that redistributes or downloads third-party data,
the wrapper license does **not** clear the component licenses, and this is flagged.

> **F500 caveat — generated text.** Several corpora (RAGTruth, HaluEval, FActScore bios,
> SelfCheckGPT) contain text generated by OpenAI / Meta models. The *dataset* license is
> separate from those providers' model-output / training terms, which is an independent
> legal axis your counsel should review before using such data to *train* a model.

## 1. Fact-verification / NLI core

### FEVER — Fact Extraction and VERification
- **Paper:** Thorne, Vlachos, Christodoulopoulos & Mittal, 2018 — NAACL-HLT 2018 (arXiv:1803.05355). [1]
- **URL:** https://huggingface.co/datasets/fever/fever · https://fever.ai/dataset/fever.html · https://aclanthology.org/N18-1074/
- **License:** CC BY-SA 3.0 **and** GPL-3.0 (annotations incorporate Wikipedia material; HF card lists both).
- **Size:** 185,445 claims (v1.0 training expands to 311,431 evidence-paired rows; v2.0 adds 1,174 adversarial).
- **Labels:** SUPPORTED / REFUTED / NOTENOUGHINFO.
- **Fits:** ClaimEntailmentVerifier — canonical claim-vs-Wikipedia-evidence verification; 1:1 with supported/contradicted/unverifiable.
- **Commercial:** **Conditional** — CC BY-SA permits commercial use with attribution + share-alike; the parallel GPL-3.0 listing adds copyleft obligations.

### FEVEROUS — FEVER Over Unstructured and Structured information
- **Paper:** Aly, Guo, Schlichtkrull, Thorne, Vlachos, Christodoulopoulos, Cocarascu & Mittal, 2021 — NeurIPS 2021 Datasets & Benchmarks (arXiv:2106.05707). [2]
- **URL:** https://huggingface.co/datasets/fever/feverous · https://fever.ai/dataset/feverous.html
- **License:** Wikipedia article terms, falling back to CC BY-SA 3.0.
- **Size:** 87,026 verified claims, each with evidence as sentences and/or table cells.
- **Labels:** SUPPORTED / REFUTED / NOTENOUGHINFO.
- **Fits:** ClaimEntailmentVerifier — claim verification over **mixed structured (tables) + unstructured (text)** evidence.
- **Commercial:** **Conditional** — CC BY-SA share-alike, no explicit NC bar.

### VitaminC
- **Paper:** Schuster, Fisch & Barzilay, 2021 — NAACL 2021 (arXiv:2103.08541). [3]
- **URL:** https://huggingface.co/datasets/tals/vitaminc · https://github.com/TalSchuster/VitaminC
- **License:** CC BY-SA 3.0 (HF card `cc-by-sa-3.0`).
- **Size:** ~488,904 examples on HF (train 371k / val 63.1k / test 55.2k); paper headline "450,000+ claim-evidence pairs."
- **Labels:** SUPPORTS / REFUTES / NOT ENOUGH INFO.
- **Fits:** ClaimEntailmentVerifier robustness — **contrastive** minimal-pair evidence (near-identical evidence, opposite verdicts) forces judgments to track evidence; also useful for CrossExaminer sensitivity.
- **Commercial:** **Conditional** — CC BY-SA, no NC restriction.

### ANLI — Adversarial Natural Language Inference
- **Paper:** Nie, Williams, Dinan, Bansal, Weston & Kiela, 2020 — ACL 2020 (arXiv:1910.14599). [4]
- **URL:** https://huggingface.co/datasets/facebook/anli · https://github.com/facebookresearch/anli
- **License:** **CC BY-NC 4.0** (HF card).
- **Size:** 169,265 rows across three human-and-model-in-the-loop rounds (R1/R2/R3).
- **Labels:** entailment / neutral / contradiction.
- **Fits:** ClaimEntailmentVerifier — the hardest stress test for the entailment backbone.
- **Commercial:** ⚠️ **NO** — CC BY-NC 4.0 prohibits commercial use. Research-only.

### MultiNLI — Multi-Genre NLI
- **Paper:** Williams, Nangia & Bowman, 2018 — NAACL-HLT 2018 (arXiv:1704.05426). [5]
- **URL:** https://huggingface.co/datasets/nyu-mll/multi_nli · https://cims.nyu.edu/~sbowman/multinli/
- **License:** Mostly OANC (Open American National Corpus) permissive; HF tags also list CC BY 3.0, CC BY-SA 3.0, MIT, and "other" (varied source genres).
- **Size:** 433,000 sentence pairs across genres (matched/mismatched eval).
- **Labels:** entailment / neutral / contradiction.
- **Fits:** ClaimEntailmentVerifier — general-domain NLI base for the entailment classifier.
- **Commercial:** **Yes** (attribute) — OANC + MIT/CC BY are permissive; the CC BY-SA segments carry share-alike on those portions.

### DocNLI — Document-level NLI
- **Paper:** Yin, Radev & Xiong, 2021 — Findings of ACL-IJCNLP 2021 (arXiv:2106.09449). [6]
- **URL:** https://github.com/salesforce/DocNLI · mirror https://huggingface.co/datasets/saattrupdan/doc-nli
- **License:** **BSD-3-Clause** (source repo).
- **Size:** ~1.44M pairs (train 942k / val 234k / test 267k).
- **Labels:** binary — entailment / not_entailment.
- **Fits:** ClaimEntailmentVerifier — document-granularity premise→hypothesis is exactly the retrieval-entailment shape (long evidence contexts).
- **Commercial:** **Yes** — BSD-3 permissive.

### SciFact — Verifying Scientific Claims
- **Paper:** Wadden et al., 2020 — EMNLP 2020 (arXiv:2004.14974). [7]
- **URL:** https://huggingface.co/datasets/allenai/scifact (also `allenai/scifact_entailment`) · https://github.com/allenai/scifact
- **License:** **CC BY-NC 2.0** for SciFact data; abstract corpus from S2ORC is ODC-BY 1.0.
- **Size:** 1,409 expert claims vs. a corpus of 5,183 abstracts.
- **Labels:** SUPPORT / REFUTE / NOINFO with rationale (evidence) sentences.
- **Fits:** ClaimEntailmentVerifier — canonical scientific claim verification with evidence rationales; near-perfect label match.
- **Commercial:** ⚠️ **NO** — CC BY-NC 2.0. Research-only.

### AVeriTeC — Real-world Claim Verification with Web Evidence
- **Paper:** Schlichtkrull, Guo & Vlachos, 2023 — NeurIPS 2023 Datasets & Benchmarks (arXiv:2305.13117). [8]
- **URL:** https://fever.ai/dataset/averitec.html · mirrors https://huggingface.co/datasets/pminervini/averitec
- **License:** **CC BY-NC 4.0** (official AVeriTeC/FEVER page).
- **Size:** 4,568 real-world fact-checked claims (50 fact-check orgs), QG-QA evidence structure.
- **Labels:** Supported / Refuted / Not Enough Evidence / Conflicting-Evidence-or-Cherry-picking.
- **Fits:** ClaimEntailmentVerifier — real-world verdicts vs. retrieved web evidence; "Not Enough Evidence" maps cleanly to `unverifiable`.
- **Commercial:** ⚠️ **NO** — CC BY-NC 4.0. Research-only.

## 2. Summarization-factuality / consistency

### FactCC — Factual Consistency of Abstractive Summarization
- **Paper:** Kryściński, McCann, Xiong & Socher, 2020 — EMNLP 2020 (arXiv:1910.12840). [9]
- **URL:** https://github.com/salesforce/factCC
- **License:** **BSD-3-Clause** (README adds a non-binding ethical-use request).
- **Size:** ~1.0M synthetic training examples; manually annotated val=931, test=503 (441 consistent / 62 inconsistent).
- **Labels:** CORRECT / INCORRECT (plus span annotations).
- **Fits:** ClaimEntailmentVerifier — (source-doc, summary-sentence) binary consistency maps to supported/contradicted.
- **Commercial:** **Yes** — BSD-3 (honor the ethical note).

### SummaC — NLI-based Inconsistency Detection benchmark
- **Paper:** Laban, Schnabel, Bennett & Hearst, 2022 — TACL vol. 10 (arXiv:2111.09525). [10]
- **URL:** https://github.com/tingofurro/summac (PyPI `summac`)
- **License:** **Apache-2.0** (wrapper/code).
- **Size:** Meta-benchmark of 6 datasets (CoGenSumm, XSumFaith, Polytope, FactCC, SummEval, FRANK); ~2,800-example standardized test set.
- **Labels:** binary consistent / inconsistent (some components retain error-type sublabels).
- **Fits:** ClaimEntailmentVerifier — NLI/entailment for document-vs-summary consistency.
- **Commercial:** **Conditional** — Apache-2.0 covers the wrapper only; the **6 component datasets each carry their own licenses** (CNN/DM, XSum derivatives). Clear per component.

### AggreFact — Aggregated summarization-factuality benchmark
- **Paper:** Tang, Goyal, Fabbri et al., 2023 — ACL 2023 (arXiv:2205.14540; ACL 2023.acl-long.650). [11]
- **URL:** https://github.com/Liyan06/AggreFact
- **License:** ⚠️ **NO LICENSE FILE** (verified: `/blob/main/LICENSE` → 404, no badge) → default all-rights-reserved.
- **Size:** Aggregates 9 datasets into AGGREFACT-CNN and AGGREFACT-XSUM (a few thousand annotated (article, summary) pairs), stratified OLD / EXFORMER / FTSOTA.
- **Labels:** binary 1=consistent / 0=inconsistent (+ unified error-type taxonomy).
- **Fits:** ClaimEntailmentVerifier — binary supported/contradicted supervision; model-era strata also support CrossExaminer-style robustness comparisons.
- **Commercial:** ⚠️ **No / unclear — FLAGGED.** Repo grants no license **and** inherits 9 component licenses. Do not use commercially without contacting the authors.

### TRUE — Re-evaluating Factual Consistency Evaluation (Google)
- **Paper:** Honovich, Aharoni, Herzig et al., 2022 — NAACL 2022 (arXiv:2204.04991). [12]
- **URL:** https://github.com/google-research/true · https://research.google/pubs/true-re-evaluating-factual-consistency-evaluation/
- **License:** **Apache-2.0** (download/standardization scripts).
- **Size:** Meta-benchmark of 11 datasets (FRANK, SummEval, MNBM, QAGS-CNNDM, QAGS-XSum, BEGIN, Q², DialFact, PAWS, FEVER, VitaminC).
- **Labels:** unified binary 1=consistent / 0=inconsistent w.r.t. grounding.
- **Fits:** ClaimEntailmentVerifier — unified (grounding, generated_text → consistent?) format across summarization, dialogue, and fact-verification; strong retrieval-entailment generalization signal.
- **Commercial:** **Conditional** — Apache-2.0 wrapper does **not** redistribute data; each of 11 components carries its own license. Clear per source.

## 3. LLM hallucination / long-form factuality

### RAGTruth — Hallucination corpus for RAG
- **Paper:** Wu, Zhu, Xu et al., 2024 — ACL 2024 (arXiv:2401.00396; ACL 2024.acl-long.585). [13]
- **URL:** https://github.com/ParticleMedia/RAGTruth (dataset under `/dataset`)
- **License:** **MIT** (repo root).
- **Size:** ~17,790 responses over 2,965 source instances; 7,664 responses have word-level hallucination annotations (6 LLMs × QA / data-to-text / summarization).
- **Labels:** span/word-level hallucination types — Evident Conflict, Subtle Conflict, Evident Baseless Info, Subtle Baseless Info — plus case-level hallucinated/non-hallucinated.
- **Fits:** ClaimEntailmentVerifier — spans judged against retrieved RAG context (supported vs. contradicted/baseless) = retrieval-entailment, the closest public analogue to the Perathos RAG setting.
- **Commercial:** **Yes** — MIT (generated-text caveat applies).

### FActScore — Atomic Factual Precision in Long-Form Text
- **Paper:** Min, Krishna, Lyu et al., 2023 — EMNLP 2023 (arXiv:2305.14251; ACL 2023.emnlp-main.741). [14]
- **URL:** https://github.com/shmsw25/FActScore (PyPI `factscore`)
- **License:** **MIT** (code + released atomic-fact data); evidence is Wikipedia (CC BY-SA).
- **Size:** ~500-person main eval, 183 labeled; broader release covers 601 individuals; FActScore-Rare = 198.
- **Labels:** per atomic fact — Supported (S) / Not-Supported (NS); metric = % supported.
- **Fits:** ClaimEntailmentVerifier — the canonical atomic-claim → supported/not-supported-vs-evidence task; near 1:1 with the verifier's label space.
- **Commercial:** **Yes (conditional)** — MIT artifact; Wikipedia evidence is CC BY-SA if redistributed.

### SAFE / LongFact (Google DeepMind)
- **Paper:** Wei, Yang et al., 2024 — "Long-form factuality in large language models" (arXiv:2403.18802; NeurIPS 2024). [15]
- **URL:** https://github.com/google-deepmind/long-form-factuality
- **License:** **Apache-2.0** (code) + **CC BY 4.0** (data) — both permissive.
- **Size:** LongFact-Objects 1,140 + LongFact-Concepts 1,140 = 2,280 fact-seeking prompts; SAFE validated on ~16,000 atomic facts.
- **Labels:** SAFE labels each atomic fact Supported / Not-Supported / Irrelevant; metric F1@K.
- **Fits:** ClaimEntailmentVerifier — Supported/Not-Supported/Irrelevant maps exactly onto supported/contradicted/unverifiable, with retrieval grounding.
- **Commercial:** **Yes** — Apache-2.0 + CC BY 4.0 (attribution).

### SelfCheckGPT — WikiBio-GPT3 (`wiki_bio_gpt3_hallucination`)
- **Paper:** Manakul, Liusie & Gales, 2023 — EMNLP 2023 (arXiv:2303.08896). [16]
- **URL:** https://huggingface.co/datasets/potsawee/wiki_bio_gpt3_hallucination · https://github.com/potsawee/selfcheckgpt
- **License:** **CC BY-SA 3.0** (HF card) — share-alike copyleft.
- **Size:** 238 annotated passages (v3), split into sentences; GPT-3 (text-davinci-003) bios.
- **Labels:** sentence-level accurate / minor_inaccurate / major_inaccurate.
- **Fits:** **CrossExaminer** — the canonical **self-consistency resampling** method (sample multiple stochastic generations, measure agreement). Also serves ClaimEntailmentVerifier as sentence-level factuality labels. This is the single best public anchor for CrossExaminer.
- **Commercial:** **Conditional** — CC BY-SA 3.0 permits commercial use but redistributed derivatives must stay CC BY-SA (problematic if bundling into a closed dataset).

### HaluEval — Hallucination Evaluation Benchmark
- **Paper:** Li, Cheng, Zhao, Nie & Wen, 2023 — EMNLP 2023 (arXiv:2305.11747; ACL 2023.emnlp-main.397). [17]
- **URL:** https://github.com/RUCAIBox/HaluEval (data in `/data`)
- **License:** **MIT** (official RUCAIBox repo LICENSE; some secondary sources mis-state Apache-2.0 — trust the repo).
- **Size:** 35,000 examples (10k QA + 10k dialogue + 10k summarization right/hallucinated pairs) + 5,000 general ChatGPT queries with human annotation.
- **Labels:** paired `right_*` vs `hallucinated_*` per task; general split binary hallucination Yes/No.
- **Fits:** ClaimEntailmentVerifier — knowledge-grounded right-vs-hallucinated pairs test content contradicted/unsupported by provided context.
- **Commercial:** **Yes** — MIT (generated-text caveat applies).

## 4. QA-factuality / claim attribution

### FELM — Factuality Evaluation of LLMs
- **Paper:** Chen et al., 2023 — NeurIPS 2023 Datasets & Benchmarks (arXiv:2310.00741). [18]
- **URL:** https://huggingface.co/datasets/hkust-nlp/felm · https://github.com/hkust-nlp/felm
- **License:** **CC BY-NC-SA 4.0** — non-commercial + share-alike.
- **Size:** 847 samples across 5 subsets (math 194, reasoning 208, world-knowledge 184, science 125, writing_rec 136), segment-level annotations.
- **Labels:** segment-level true / false (+ error-type tags, reasons, reference links).
- **Fits:** ClaimEntailmentVerifier — segment-level true/false maps to supported/contradicted.
- **Commercial:** ⚠️ **NO** — CC BY-NC-SA 4.0. Research-only.

### TruthfulQA
- **Paper:** Lin, Hilton & Evans, 2021 (publ. ACL 2022) (arXiv:2109.07958). [19]
- **URL:** https://huggingface.co/datasets/truthfulqa/truthful_qa · https://github.com/sylinrl/TruthfulQA
- **License:** **Apache-2.0** (HF card).
- **Size:** 817 questions / 38 categories; `generation` and `multiple_choice` configs.
- **Labels:** generation = best/correct/incorrect answer sets; MC = mc1/mc2 binary correct/incorrect. (Not a 3-way NLI scheme; no retrieved-evidence pairing.)
- **Fits:** **CrossExaminer** — correct/incorrect answer sets support self-consistency / truthfulness scoring. Weaker fit for ClaimEntailmentVerifier (no evidence pairing).
- **Commercial:** **Yes** — Apache-2.0.

### ExpertQA — Expert-Curated Questions and Attributed Answers
- **Paper:** Malaviya et al., 2023 (NAACL 2024) (arXiv:2309.07852). [20]
- **URL:** https://huggingface.co/datasets/cmalaviya/expertqa · https://github.com/chaitanyamalaviya/ExpertQA
- **License:** **MIT** (repo LICENSE).
- **Size:** 2,177 validated examples across 32 fields from 484 experts (2,507 collected).
- **Labels:** claim-level attribution support status (supported / not-fully-supported, with reasons), source reliability, correctness, informativeness, computed fact_score.
- **Fits:** ClaimEntailmentVerifier — per-claim support status against evidence passages = supported/contradicted/unverifiable with attached evidence.
- **Commercial:** **Yes** — MIT (cited source content may carry its own terms).

### WiCE — Real-World Entailment for Claims in Wikipedia
- **Paper:** Kamoi et al., 2023 — EMNLP 2023 Findings (arXiv:2303.01432). [21]
- **URL:** https://github.com/ryokamoi/wice · mirror https://huggingface.co/datasets/tasksource/wice
- **License:** Dual — dataset CC BY-SA (Wikipedia-derived claims) + ODC-BY (annotations); code MIT (repo LICENSE.md).
- **Size:** ~5,377 claim–evidence pairs with train/dev/test splits.
- **Labels:** sub-sentence 3-way supported / partially_supported / not_supported, plus minimal supporting-evidence subset per subclaim.
- **Fits:** ClaimEntailmentVerifier — purpose-built for atomic/sub-claim entailment vs. retrieved evidence with partial-support granularity (closest public match to atomic-claim decomposition).
- **Commercial:** **Conditional** — claim text inherits Wikipedia CC BY-SA (share-alike); annotations ODC-BY; code MIT. Usable commercially only if you accept share-alike on the Wikipedia-derived content; treat as restricted.

## Recommended starter recipe

Fine-tune the ClaimEntailmentVerifier model first on a small, **permissively licensed,
evidence-grounded** mix — avoiding NC datasets entirely so the trained checkpoint stays
commercially shippable:

1. **FActScore (MIT)** — the closest public match to Perathos's actual task:
   atomic-claim → Supported/Not-Supported against retrieved Wikipedia evidence. Teaches
   the model the atomic-decomposition + evidence-grounding pattern directly.
2. **RAGTruth (MIT)** — adds the **RAG** dimension: spans judged against retrieved context
   with a four-way conflict/baseless taxonomy that distinguishes `contradicted`
   (conflict) from `unverifiable` (baseless) — exactly Perathos's third label.
3. **DocNLI (BSD-3) or SAFE/LongFact (Apache-2.0 + CC BY 4.0)** — choose by need:
   DocNLI for high-volume long-context entailment pretraining (~1.44M pairs) to harden the
   entailment backbone; SAFE/LongFact for a clean Supported/Not-Supported/**Irrelevant**
   three-way that mirrors supported/contradicted/unverifiable on long-form generations.

All three core picks (FActScore, RAGTruth, DocNLI/SAFE) are **commercial-OK** and
evidence-grounded. Add **VitaminC** (CC BY-SA, contrastive) only if you accept share-alike,
because its minimal-pair structure is the single best robustness signal — but it should be
a *robustness add-on*, not part of the shippable base, due to copyleft.

For **CrossExaminer**, the public anchor is **SelfCheckGPT / WikiBio-GPT3** (CC BY-SA 3.0,
research/conditional), supplemented by **TruthfulQA** (Apache-2.0) for truthfulness scoring.
CrossExaminer's signal (resample disagreement) is largely *unsupervised* and produced at
inference time, so these serve mainly to **validate/calibrate** the disagreement threshold
rather than to train weights.

## Calibration data

Verifier confidence must be calibrated so that a reported probability matches empirical
accuracy (low ECE / good reliability diagram). This requires **held-out, in-domain,
human-labeled (claim, evidence, label) triples that the model never trained on**:

- **What's needed:** a few hundred-to-low-thousands of triples per target domain, with
  gold `supported` / `contradicted` / `unverifiable` labels and the retrieved evidence
  actually shown to the verifier. Stratify by claim type (numeric, named-entity, causal),
  evidence sufficiency (single-hop / multi-hop / not-enough-info), and difficulty.
- **How to source it cheaply:**
  - Carve **held-out test splits** from the permissive datasets above (FActScore,
    RAGTruth, SAFE/LongFact, DocNLI test) and *exclude them from training*. These give
    free in-distribution calibration triples with the right label space.
  - Use **VitaminC's contrastive pairs** and **AVeriTeC's "Not Enough Evidence"** items
    (research-only) as a *diagnostic* calibration set for the `unverifiable` boundary,
    where models are typically worst-calibrated — keep these separate from any commercial
    training/eval if NC matters.
- **How to build the gold standard for *your* domain:** the public sets are general/encyclopedic;
  Perathos's production traffic is not. Sample real verifier inputs (claim + retrieved
  evidence), have 2–3 annotators label each triple, adjudicate disagreements, and measure
  inter-annotator agreement (Cohen's/Fleiss' κ) — target κ ≥ 0.7 before trusting the set.
  Then fit a post-hoc calibrator (temperature scaling or isotonic regression) on this
  held-out set and report ECE + a reliability diagram per domain.
- **For CrossExaminer:** calibrate the **disagreement-rate → hallucination-probability**
  mapping on a labeled subset where you have both the resample distribution *and* a gold
  hallucinated/faithful label (SelfCheckGPT provides exactly this pairing for anchoring;
  a held-out slice of your own labeled traffic is essential for the production threshold).

  OpenAI/Meta-generated text; the dataset license is independent of those providers'
