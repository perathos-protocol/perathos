An open-source flight recorder for coding agents.

Every tool call is chained, signed and independently timestamped, and destructive actions need a signed safety check first. After an incident you can show what the agent did, that nothing was cut from the record, and whether the safeguards were in place.

Install (Claude Code)

pip install 'perathos[anchor]'
perathos keygen
perathos hooks install --guard --anchor

Records every tool call, blocks destructive commands unless a person has signed a safety check, and timestamps each checkpoint with an RFC 3161 authority.

What you get

  • Recorder. A hash-chained receipt for every tool call (hashes of arguments and results, never the content), sealed each turn by an Ed25519-signed checkpoint.
  • Independent time. Checkpoints are timestamped by an outside authority, so the log cannot be back-dated and a cut-off ending is detectable.
  • Guard. Commands like rm -rf, DROP TABLE or terraform destroy are blocked unless a person has run a signed precondition check. The agent cannot approve itself.
  • Evidence pack. perathos session export writes a signed bundle with a one-page report that anyone can re-check with perathos evidence verify, or in the browser verifier.

Honest limits

Perathos proves which key sealed the record, not which model ran. The guard is a seatbelt, not a sandbox: it stops accidents, not a determined hostile agent. The full list is in the receipt spec.
