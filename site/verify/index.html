Evidence verifier

Drop a Perathos evidence pack (.zip) to check, in this browser, that every file matches the signed manifest, that the receipt chain is unbroken and every checkpoint signature is valid, and that the head witness and timestamp anchors line up with the log. It does not verify the RFC 3161 timestamp signatures themselves (use perathos evidence verify for that), and it cannot tell you which model ran or whether the signer key really belongs to who you think: confirm the key separately.

Nothing is uploaded: the pack is read and checked locally, and this page makes no network requests except to load itself, JSZip and (only on browsers without built-in Ed25519) a signature library.

Loads the PocketOS replay pack from this site.
If set, a pack signed by any other key fails.

What a VERIFIED result means

  • The holder of the signer key sealed exactly these receipts, and nothing up to the last checkpoint was edited, removed, inserted or reordered since.
  • It proves which key sealed the record, not which model ran (the model name is self-reported).
  • Event times come from the local clock; only anchored checkpoints have an independent time, and this page checks the anchors' link to the log, not the timestamp authority's signature.
  • Tool arguments and outputs are not in the pack, only their SHA-256 hashes.
  • The guard is a seatbelt, not a sandbox: it matches command patterns.
Receipt format: RECEIPT_V1. No cookies, no analytics.
